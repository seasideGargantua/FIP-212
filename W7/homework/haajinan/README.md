## W7_lab 第三组作业

#### 已排序列表的退化测试

输入：
```
[1, 2, 3, 4, 5, 6, 7, 8]
```
发现每次分区后left为空，right有n-1个元素<br>
共进行了n-1次分区，递归深度是n<br>
使得算法的时间复杂度退化为$O(n^2)$

#### 手工分区游戏

|---|---|---|---|
| [8, 3, 5, 1, 7, 2, 9, 4] | [3, 1, 2, 4] | [8, 7, 9] | 在left和right之间 |
