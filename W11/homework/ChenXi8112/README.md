## 研讨课二：BST 项目

1. **项目代码（二选一）**：选项目 A，代码在 `bst_build_search.py`（BST 构建与查找）
2. **手绘 BST 过程图**：`bst_building.jpg`
3. **查找策略反思（1 句话）**：本次任务动态插入数据，BST 平均 O(log n) 的插入和查找且无需像排序数组那样 O(n) 搬移元素；代价是插入顺序接近有序时会退化成链表、最坏 O(n)，需用平衡树才能稳定保持对数性能。

**项目 A 补充答案**：

- 查找 40：50 → 30 → 40（True）
- 查找 65：50 → 70 → 60（False；60 没有右子树）
- 查找 80：50 → 70 → 80（True）
- 中序遍历：20 30 40 50 60 70 80，严格递增，说明这棵树满足 BST 性质。
