#### 项目选择说明
我们组选择了A 循环队列，因为这与上节课的知识关联性强，并且能帮助我们学习类与对象的有关知识。
#### 反思
**循环队列如何复用空间：** 引入了`front`和`rear`两个变量(即双指针),分别用来判断读和写，并使用`%`取余循环，使得过去的'无用'空间能够复用  
相比在讲座课前期我们学到的循环队列，A 循环队列有两个好处：  
**1.** 引入了`count`属性，使得在不用'浪费'一个空位用于判断队列是否已满的同时，也可以查看队列目前的元素数量  
**2.** 使用`%`取余运算来避免`if`判断，提高了代码运行效率，也更加优雅
